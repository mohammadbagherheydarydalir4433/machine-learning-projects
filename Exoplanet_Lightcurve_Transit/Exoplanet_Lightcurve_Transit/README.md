# Exoplanet Lightcurve Transit Analysis (Kepler)

تحلیل و پیش‌پردازش منحنی نور (**Light Curve**) ستاره‌های مأموریت **Kepler** با `lightkurve` و پایتون در نوت‌بوک `nasa.ipynb` برای بررسی سیارات فراخورشیدی در برابر موارد مثبت کاذب.

## خلاصه مراحل انجام‌شده
* **دریافت و پاک‌سازی داده:** دریافت منحنی نور، حذف مقادیر `NaN` و نقاط پرت (`remove_outliers`) و نرمال‌سازی (`normalize`).
* **هموارسازی و هم‌فازسازی:** حذف روندهای کند با `flatten`، هم‌فاز کردن بر اساس دوره تناوب و زمان میانه گذر و باینینگ حول مرکز گذر (`Phase = 0`).
* **استخراج ویژگی:** استخراج `baseline_flux`، `min_flux`، `transit_depth`، `flux_std`، `snr_proxy` و `asymmetry`.

## حقوق مالکیت و شرایط استفاده
این پروژه صرفاً جهت نمایش نمونه‌کار و مطالعه منتشر شده است. حق مالکیت معنوی اثر متعلق به سازنده مخزن است و هرگونه کپی‌برداری، بازنشر، تغییر یا بهره‌برداری تجاری بدون کسب اجازه کتبی یا ذکر منبع صریح مجاز نیست. ویرایش مستقیم این مخزن تنها برای مالک حساب امکان‌پذیر است.
